# akihub

アキの作業場兼ハブリポジトリ。人間の情報スクラップと AI オーケストレーション知見を置く場所。

ビルドは不要。継続的なブラッシュアップは AI オーケストレーションが担う。

## 構成

- `LLMtotadasikukaiwasuruhouhou.md` — LLMと正しく会話する方法（資料）
- `TODO/` — 未整理タスク
- `tools/` — ユーティリティ
  - `codex-todo-hub-observer/` — Codex TODOハブ監視スキル
  - `gpt-sh/` — GPTシェル関連
- `マジックワード案/` — プロンプト実験メモ

## 運用

- スクラップ品はそのまま置く
- AI が整理・更新を担当
- Issue と PR で管理

# マジックワード案

人間が長い指示を書かなくても、LLMに読む範囲と判断範囲を短く伝えるための省略記法。

## 基本ルール

- まず、対象ファイルや対象ディレクトリを明示する
- その後ろに、読む深さ、読む量、判断条件を短縮記法で並べる
- 省略記法は左から順に適用する

例:

```text
just -> 1file -> 200 -> ok
```

意味:

1. `justfile` を先に読む
2. `justfile` から直接参照しているファイルを1段先まで読む
3. 各ファイルは先頭200文字だけ読む
4. その範囲で判断してよい

## コア記法

### `just`

- 指定された `justfile` を最初に読む
- `just` の説明や差分確認では、まずこのファイルを根拠にする

例:

```text
just
```

意味:

- `justfile` を読む

### `1file`

- 今見ているファイルから、直接参照しているファイルを1段先だけ読む
- 2段先、3段先までは追わない

例:

```text
just -> 1file
```

意味:

- `justfile` を読む
- レシピ内で直接実行しているスクリプトや参照ファイルを1つ先まで読む

### `200`

- 各ファイルは先頭200文字だけ読む
- 大ざっぱに見るだけでよい、という意味

目安:

- 英数字中心なら約0.2KB
- 日本語が多いUTF-8なら約0.6KB前後

例:

```text
just -> 1file -> 200
```

意味:

- `justfile` を読む
- 1段先の参照先も読む
- ただし各ファイルの先頭200文字だけ見る

### `20l`

- 各ファイルは先頭20行だけ読む
- コードや設定ファイルは、`200` よりこちらのほうが安定しやすい

例:

```text
just -> 1file -> 20l
```

意味:

- `justfile` を読む
- 1段先の参照先も読む
- 各ファイルの先頭20行だけ見る

### `ok`

- 指定された範囲だけで判断してよい
- 追加探索や深掘りをしなくてよい

例:

```text
just -> 1file -> 200 -> ok
```

意味:

- `justfile` と1段先の参照先だけを、各200文字まで読んで判断する

## よく使う組み合わせ

### `just -> 1file -> 200 -> ok`

用途:

- `justfile` の説明や、軽い差分確認

意味:

- `justfile` を読む
- 直接参照先を1段だけ追う
- 各ファイルは先頭200文字だけ読む
- その範囲で答える

### `just -> 1file -> 20l -> ok`

用途:

- `justfile` とスクリプトの冒頭構造を見たい時

意味:

- `justfile` を読む
- 直接参照先を1段だけ追う
- 各ファイルは先頭20行だけ読む
- その範囲で答える

### `just -> 0file -> 200 -> ok`

用途:

- `justfile` 内のコメントだけ見れば足りる時

意味:

- `justfile` だけ読む
- 参照先は追わない
- 先頭200文字だけ見る
- その範囲で答える

## 補助記法

### `0file`

- 今見ているファイルだけ読む
- 参照先は読まない

### `deep`

- 1段では足りない場合、参照先を必要な範囲でもう少し追ってよい
- ただし、明示されていない限り乱用しない

### `strict`

- 推測を減らす
- ファイルに書いてある内容だけを根拠に答える

### `fast`

- ざっくり判断を優先する
- 厳密さより、先に方向を出す

## 推奨テンプレート

### 1. `justfile` 説明用

```text
対象: tools/gpt-sh/justfile
just -> 1file -> 200 -> ok
```

### 2. コメントを根拠に答えさせたい時

```text
対象: tools/gpt-sh/justfile
just -> 0file -> 200 -> strict
```

### 3. 入口だけ見て素早く判断したい時

```text
対象: tools/gpt-sh/justfile
just -> 1file -> fast -> ok
```

## 運用メモ

- 人間向けの自然文を毎回がんばらないための記法
- 「ちゃんと読んでから答えろ」を、短い命令に圧縮するためのもの
- 重要なのは、対象パスを先に書くこと
- 記法だけを書くと、何を読むべきかぶれやすい

## 最小セット

最初はこれだけでも十分:

- `just`
- `1file`
- `200`
- `20l`
- `ok`

最小例:

```text
対象: tools/gpt-sh/justfile
just -> 1file -> 200 -> ok
```
